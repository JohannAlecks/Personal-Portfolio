## Getting Started

### Prerequisites

- Node.js 20 or later
- npm

### Installation

```bash
git clone https://github.com/JohannAlecks/Personal-Portfolio.git
cd Personal-Portfolio
npm install
```

### Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Available commands

```bash
npm run dev    # Start the development server
npm run lint   # Run ESLint
npm run build  # Create a production build
npm run start  # Start the production server
```

## Environment Variables

The current portfolio does not require application environment variables. The contact form uses a Formspree endpoint configured in the contact section.

If the Formspree endpoint or another external service is moved to an environment variable in the future, create a `.env.local` file in the project root and document only the variable names, never their secret values:

```env
NEXT_PUBLIC_FORMSPREE_ENDPOINT=your_formspree_endpoint
```

Never commit `.env.local` or any secret API keys to Git.

## Deployment

The portfolio is deployed with [Vercel](https://vercel.com). To deploy your own version:

1. Import the GitHub repository into Vercel.
2. Keep the framework preset as Next.js.
3. Use `npm run build` as the production build command if Vercel does not detect it automatically.
4. Deploy and connect a custom domain if needed.
